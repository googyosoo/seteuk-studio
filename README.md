# 세특 스튜디오 (Seteuk Studio)

> **선생님의 관찰과 기록에 집중하는 학교생활기록부 교과 세특 고도화 웹앱**  
> 2022 개정 교육과정 성취기준 연계 · NEIS 1,500 Byte 규격 준수 · 기재금지어 실시간 감사 · Zero-DB 프라이버시 보호

---

## 📌 주요 특징 및 기능

### 1. 학생 관찰 메모 기반 4층 서사 완성형 초안 생성
- 학생의 수업 참여 메모, 발표 대본, 탐구 보고서 등 거친 메모를 바탕으로 **질문(탐구동기) → 계획(탐구설계) → 수행(교과역량) → 심화(성장도약)**의 4층 구조 세특 초안을 생성합니다.
- 과목별 2022 개정 교육과정 표준 성취기준과 추천 수행평가 활동을 원클릭으로 연계할 수 있습니다.

### 2. NEIS 공식 바이트 & 글자수 실시간 게이지
- **공백 포함 전체 글자수**와 NEIS 공식 환산 바이트(한글 3B, 영문·숫자·공백·줄바꿈 1B)를 실시간으로 계산합니다.
- 과목별 최대 한도인 **1,500 Byte** 초과 여부를 색상별 게이지로 직관적으로 경고하며, 추천 안전 구간(1,350B ~ 1,480B)을 안내합니다.

### 3. 기재금지어 2차 독립 실시간 감사 (Dual-Layer Audit)
교육부 학교생활기록부 기재요령에 따른 위반 소지를 실시간 감지하여 경고합니다:
- **공인어학시험**: TOEIC, TOEFL, TEPS, OPIC, HSK, JLPT 등
- **교외 대회 및 수상**: 교외대회, 올림피아드, 경시대회, 공모전, 금상, 은상 등
- **논문 및 출판물**: 소논문, 학술지, 저널, 도서출간, 특허 등
- **대학교명 및 외부기관**: 대학명(서울대, 연세대, 하버드 등), 영재교육원, 사설학원 등
- **상용 플랫폼 및 브랜드**: 유튜브, ChatGPT, 구글, 파파고, 네이버 등
- **부모 및 친인척 직업/지위**: 의사, 교수, 변호사 등 사회·경제적 지위 암시 서술

### 4. 교사 고유 문체 퓨샷(Few-shot) 학습 & 50개 교과 전문 동사
- 선생님께서 평소 작성하셨던 우수 세특 문장(1~3문장)을 입력하면 AI가 문장 호흡과 종결 어미 스타일을 그대로 계승합니다.
- `구조화함`, `모델링함`, `진단함`, `재해석함`, `정량화함` 등 50여 개 교과 전문 능동 동사를 적용합니다.

### 5. 학급 전체 어휘 중복도 검사 & 유의어 자동 분산
- 학급 전체 세특 초안의 2-gram/3-gram 연속 구절 및 클리셰(`적극적인 태도로`, `우수한 학업 성취` 등)를 교차 분석합니다.
- 원클릭으로 학생마다 서로 다른 유의어로 순환 교체하여 복사-붙여넣기 의심을 원천 차단합니다.

### 6. 다채로운 출력 & 나이스 분할 모드 (1:1 도크)
- **엑셀(.xlsx) 및 CSV 내보내기**: 학급 명단 전체의 원문, 고도화 세특, 바이트수, 기재금지 감지 내역을 한 번에 내려받습니다.
- **공식 HWPX 다운로드**: 학교생활기록부 공식 서식 규격의 한글 표 문서(.hwpx)를 브라우저에서 직접 생성합니다.
- **나이스 1:1 분할 모드(Alt+C)**: 가로 380px 초슬림 미니 도크를 나이스 창 옆에 띄우고, `Alt + C` 단축키로 복사하며 다음 학생으로 자동 전진합니다.

## 🔒 개인정보 보호 & Zero-DB 세션 원칙

1. **서버 무저장 원칙 (Zero-DB)**: 백엔드 서버나 외부 데이터베이스를 일절 사용하지 않으며, 모든 데이터는 선생님의 브라우저 로컬 세션(`localStorage`)에만 안전하게 보관됩니다.
2. **식별정보 사전 마스킹 (PII Stripping)**: 외부 AI API 호출 시 학생의 이름, 학번, 이메일, 전화번호는 원천적으로 가명 처리(`[해당 학생]`, `[학번]`, `[이메일]`)되어 활동 내용만 전송되며, 결과 화면에서만 복원됩니다.

## 🔑 AI 모델 및 키 설정 (BYOK)

- **키 없이도 즉시 사용 가능**: API 키를 입력하지 않아도 화면이 정상 실행되며, 내장된 **오프라인 규칙 기반 스마트 시뮬레이터**로 전 기능을 무료로 시험해 볼 수 있습니다.
- **본인 키 직접 입력 (BYOK - Bring Your Own Key)**:
  - **Google Gemini (우선 권장)**: [Google AI Studio](https://aistudio.google.com/app/apikey)에서 무료 등급 API 키를 발급받아 등록하면 빠른 속도로 무제한에 가깝게 활용할 수 있습니다.
  - **Upstage Solar**: 한국어 자연어 및 세특 문체에 특화된 Solar Pro 모델 지원.
  - **Anthropic Claude**: Claude 3.7 Sonnet / 3.5 Sonnet 지원.
  - **OpenAI GPT**: GPT-4o / GPT-4o Mini 지원.

## 💻 로컬 실행 방법

```bash
# 1. 저장소 클론
git clone https://github.com/<사용자명>/seteuk-studio.git
cd seteuk-studio

# 2. 의존성 패키지 설치
npm install

# 3. 개발 서버 실행
npm run dev
# 브라우저에서 http://localhost:5173 접속
```
